# 已发布文章二次编辑与再发布（无缝衔接）

本项目的内容源已收敛为 **DB（Postgres）**：
- 站点只展示 `posts` 表里 `status='published'` 的文章

因此要实现“已发布文章可二次编辑并再次发布”，核心是：
1) 能把已发布文章**重新载入编辑器**
2) 编辑后通过既有发布接口**再次奉纳（upsert published）**，触发缓存刷新

---

## 使用方式

### 1) 编辑已发布文章（DB published）
1. 打开文章详情页：`/blog/<slug>`
2. 若你已登录写作会话，会看到右上角 **“编辑”** 按钮
3. 点击后进入：`/write?slug=<slug>`，载入文章后直接修改
4. 点击右上角 **“奉纳”** 重新发布（会保持 published）

> 注意：在已发布文章上点击“草稿”会将其保存为 `draft`，从站点下线；编辑器会弹窗二次确认。

---

## 相关实现点（便于维护）
- `/write` 设置面板新增文章列表（DB），支持筛选与搜索
- 文章详情页新增客户端鉴权的“编辑”入口（避免让文章页变成动态渲染）
- `slug` 做了更严格的校验以避免路径穿越与异常输入
