# 纯净背景模式设计

## 目标

为博客前台增加一个独立的“纯净背景”开关。

- 浅色模式下，将页面大背景切换为纯白。
- 深色模式下，将页面大背景切换为纯黑。
- 不改变卡片、主题色、阴影、导航和组件内部视觉语言。

## 范围

仅调整全站页面的大背景层：

- `body` 背景色
- `.nh-page::before` 背景图层
- `.nh-page::after` 背景叠加层

不调整以下内容：

- 卡片透明度逻辑
- 主题色逻辑
- 深色模式开关语义
- 组件局部样式

## 交互设计

- 在现有“显示设置”中新增“纯净背景”独立开关。
- 开关为手动切换。
- 与“深色模式”并列，不互相替代。
- 左右侧设置面板状态保持同步。
- 刷新页面后保留用户选择。

## 技术设计

- 新增 `cleanBackground` 外观状态。
- 状态沿用现有 `nh:set-appearance` / `nh:appearance-state` 事件通道同步。
- 持久化到 `localStorage`。
- 背景表现通过统一的外观工具函数计算，避免把背景判断散落在组件里。

## 验证标准

1. 设置面板出现“纯净背景”开关。
2. 开启后，首页、列表页、文章页大背景立即变为纯白或纯黑。
3. 开启纯净背景后再切换深色模式，背景可在白/黑之间同步切换。
4. 关闭纯净背景后恢复原有插画背景与叠层。
5. 刷新页面后状态保持不丢失。
